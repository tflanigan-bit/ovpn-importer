Download the .crt file above, then follow these steps on your Chromebook:

  1. Open the Files app and locate the downloaded .crt file (usually in Downloads).
  2. Double-click the .crt file. ChromeOS should recognise it as a certificate and open the import dialog automatically.
  3. A dialog will appear — click Import.
  4. When asked where to trust it, choose "For VPN and apps" (or "Authorities" if shown).
  5. Click OK / Done. The certificate is now installed.
  6. Configure your VPN at Settings → Network → VPN → Add VPN and select this certificate when prompted.
💡 If double-clicking does nothing or shows an error, switch to Method B or check the 🆘 Support tab.

Import manually via the ChromeOS Certificate Manager — works on all Chromebook versions:

  1. Open Chrome browser and go to:
    chrome://certificate-manager/ (ChromeOS 117+)
    On older versions use: chrome://settings/certificates
  2. Click the Authorities tab — this is where CA / root certificates live.
  3. Click Import and select your downloaded .crt file.
  4. In the trust dialog, check:
    ✅ Trust this certificate for identifying websites
    ✅ Trust this certificate for identifying VPN and app users
  5. Click OK — the cert should appear in the Authorities list.
  6. Go to Settings → Network → Add connection → OpenVPN / L2TP — your CA cert will be in the dropdown.
⚠ Managed Chromebook? If enrolled by a school or employer, certificate imports may be blocked. You'll need your IT admin to push it via Google Admin Console.

😶 Double-clicking the .crt file does absolutely nothing common ▼

ChromeOS sometimes loses file-type association for .crt files. Instead of double-clicking, import it directly through Chrome:

→ Fix
  1. Open Chrome and type chrome://certificate-manager/ in the address bar.
  2. Go to the Authorities tab → click Import.
  3. Navigate to your Downloads folder and select the .crt file.
  4. Check both trust boxes and click OK.
On ChromeOS 117+ you may also see a newer certificate manager at chrome://certificate-manager/ — try that first, and fall back to chrome://settings/certificates if it looks unfamiliar.
🚫 "File not supported" or "Invalid certificate" error error ▼

This usually means the file isn't a proper PEM certificate, or it has extra characters. A valid PEM file looks exactly like:

-----BEGIN CERTIFICATE----- MIIDxTCCAq2gAwIBAgIUABC... (many lines of base64) -----END CERTIFICATE----- → Fix
  1. Use the Copy PEM button above and paste it into a plain text editor (e.g. the Text app on Chromebook).
  2. Check that the first line is exactly -----BEGIN CERTIFICATE----- with no extra spaces or characters.
  3. Check that the last line is exactly -----END CERTIFICATE-----.
  4. Save the file with a .crt extension and try importing again.
⚠ If the cert block starts with -----BEGIN X509 CERTIFICATE-----, rename the header/footer to just -----BEGIN CERTIFICATE----- / -----END CERTIFICATE----- — ChromeOS requires standard PEM format.
🔘 Import button is greyed out in Certificate Manager managed ▼

A greyed-out Import button means your Chromebook is managed by an organization (school, employer, etc.) and certificate imports are restricted by policy.

→ Options
  1. Contact your IT administrator and ask them to push the CA certificate through Google Admin Console → Devices → Networks → Certificates.
  2. If you manage the domain yourself: in Google Admin Console, go to Devices → Chrome → Settings → User & Browser Settings → Security → Certificate Management and enable user certificate imports.
  3. Alternatively, if you have a personal Google account on the device, switch to it — personal accounts may have import access even on managed hardware.
If this is a personal Chromebook and the button is still greyed out, try signing out and back in, or check if Developer Mode is accidentally on (it can affect permissions).
📋 "Certificate already exists" when importing info ▼

Good news — this actually means the certificate is already installed! You don't need to import it again.

→ What to do
  1. Go to chrome://certificate-manager/ → Authorities tab and look for your VPN provider's certificate name in the list to confirm it's there.
  2. Proceed directly to setting up your VPN: Settings → Network → Add connection → OpenVPN / L2TP.
  3. In the VPN config, select the CA cert from the dropdown — it should now appear.
🔍 Certificate was imported but doesn't appear in the VPN dropdown vpn ▼

ChromeOS VPN setup only shows certificates that were trusted specifically "For VPN and apps" — if you picked a different trust level during import, it won't show up.

→ Fix
  1. Go to chrome://certificate-manager/ → Authorities tab.
  2. Find the certificate, click the ⋮ menu next to it → Edit.
  3. Make sure "Trust this certificate for identifying VPN and app users" is checked.
  4. Save → go back to the VPN setup. The cert should now appear in the dropdown.
If you don't see an Edit option, delete the certificate and re-import it, making sure to check both trust boxes this time.
🌐 VPN connects but there's no internet / traffic doesn't route vpn ▼

The certificate is fine — this is a VPN routing or configuration issue, not a cert problem.

→ Things to check
  1. Make sure Send all traffic through VPN is enabled in the VPN settings on ChromeOS (toggle in the VPN connection details).
  2. Verify your VPN server address, username, and password are correct — a typo here can cause connections that "succeed" but don't pass traffic.
  3. Check that your VPN provider's server isn't down — try their status page or a different server if available.
  4. If the server uses a custom port, make sure it's entered correctly in the VPN settings (e.g. 1194 for OpenVPN UDP, 443 for TCP).
⚠ ChromeOS's built-in VPN client only supports L2TP/IPSec and basic OpenVPN. If your VPN requires advanced OpenVPN features (tls-crypt, data-ciphers, etc.), you may need the OpenVPN for Chrome extension or an Android VPN app instead.
🔎 No certificates were extracted from my .ovpn file extractor ▼

Some .ovpn files don't embed certificates directly — instead they reference external files using lines like:

ca /etc/openvpn/ca.crt cert /etc/openvpn/client.crt key /etc/openvpn/client.key → What to do
  1. Open your .ovpn file in a text editor and look for lines starting with ca, cert, or key — they'll point to separate files.
  2. Your VPN provider should have sent those .crt / .pem files alongside the .ovpn — import those directly.
  3. If you only have the .ovpn file, contact your VPN provider and ask for the CA certificate file separately.
🔌 No "OpenVPN / L2TP" option appears in ChromeOS network settings setup ▼

The exact location of VPN settings varies slightly by ChromeOS version. Here's how to find it:

→ Where to look
  1. Click the clock / system tray in the bottom-right → click the gear icon (Settings).
  2. Go to Network → scroll down to the VPN section → click Add VPN or the + icon.
  3. You should see options for OpenVPN / L2TP and possibly WireGuard. Select OpenVPN / L2TP.
  4. If you only see WireGuard or nothing useful, your ChromeOS may be outdated — go to Settings → About ChromeOS → Check for updates.
Alternatively, try navigating to chrome://os-settings/networks?type=VPN directly in the Chrome address bar.
⚙️ ChromeOS VPN doesn't support my VPN's features — advanced config advanced ▼

The built-in ChromeOS VPN client is quite basic. If your .ovpn uses features like tls-crypt, tls-auth, data-ciphers, or fragment, it likely won't work natively. You have two better options:

→ Option 1: Android VPN app (easiest)
  1. Open the Google Play Store on your Chromebook (most Chromebooks support Android apps).
  2. Install your VPN provider's official Android app (e.g. NordVPN, ExpressVPN, ProtonVPN, Mullvad) and log in — no manual cert setup needed.
  3. Or install OpenVPN for Android (free, open source) and import your .ovpn file directly into it.
→ Option 2: OpenVPN Chrome extension
  1. Search the Chrome Web Store for "OpenVPN" — your VPN provider may have an official extension.
  2. Install it and import your .ovpn file — the extension handles all the advanced options the native client can't.
🔑 I also need to import a client key (.key file) — how? setup ▼

Client keys (.key files) are private keys — they're not imported into the certificate store. They're handled differently depending on the method:

→ Using built-in ChromeOS VPN
  1. In the Add VPN dialog, look for a field labeled User certificate — this is where you select your client certificate (the .crt extracted from the <cert> block).
  2. The private key from the <key> block is typically bundled inside a PKCS#12 (.p12) file. If your VPN provider gives you a .p12, import that at chrome://certificate-manager/ under Your certificates.
→ Easier route
  1. Use the OpenVPN for Android app on your Chromebook — it accepts the entire .ovpn file including embedded <key> blocks, so no separate import is needed.
⚠ Never share your .key / private key content with anyone or upload it to any website.
🔄 Nothing worked — how do I fully reset and start over? reset ▼

If you've gotten into a messy state, here's how to cleanly start from scratch:

→ Clean slate
  1. Go to chrome://certificate-manager/ → Authorities tab. Find any partially-imported certificates from your VPN, click ⋮ → Delete.
  2. Go to Settings → Network → VPN. Remove any broken VPN entries using the ⋮ → Forget option.
  3. Restart your Chromebook (Alt + Shift + R in the launcher, or power off and on).
  4. Come back here, re-upload your .ovpn file, download a fresh .crt, and follow Method B (Settings UI tab) from the beginning.
✅ Still stuck? Try the Android app route (see "ChromeOS VPN doesn't support my features" above) — it bypasses the native cert system entirely and is often much simpler.
